📚 Biblioteksdatabas Management System

Kurs: HI1030 Databasteknik, KTH

Labb: Programmeringslaboration 1

Termin: HT 2025

Grupp: Grupp 5 - Ibrahim & Ahmed

översikt

En JavaFX-klientapplikation som ansluter till en MySQL-databas för att hantera ett förenklat bibliotekssystem. Applikationen låter användare söka efter böcker, visa författarinformation, bläddra bland genrer och hantera bokbetyg.

Teknisk Stack

Databas: MySQL 8.0+

Applikation: Java 17+

UI-ramverk: JavaFX 19+

Byggverktyg: Maven

Databasanslutning: MySQL Connector/J (JDBC)

Designmönster: Singleton (Databasanslutning)

Arkitektur: MVC (Model-View-Controller)

Detta projekt är skapat för utbildningsändamål som en del av KTH-kursen HI1030.
